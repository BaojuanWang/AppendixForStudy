# Artifact Repository

This repository contains the study materials, analysis artifacts, interfaces, and supplementary results for the paper:

**Learning Less While Asking More: How LLM-Based Assistance Shapes Vulnerability Learning**

## Repository Structure

### `main_study/`
Materials and artifacts for the main within-subject study comparing plain LLM-based assistance with web search.

- `study_materials/`
  - `code_snippets/`: vulnerability code snippets used in the study
  - `survey/`: study survey instrument
  - `scoring_rubrics/`: rubrics used to score pre- and post-test responses
  - `coding_schemes/`: qualitative coding materials
- `plain_llm_interface/`: plain conversational LLM interface used in the main study
- `analysis/`: analysis documentation and scripts for the main study

### `vulnscaffold/`
Materials related to VulnScaffold and its pilot evaluation.

- `system/`: VulnScaffold implementation used in the pilot evaluation
- `pilot_evaluation/`: study materials and analysis artifacts for the VulnScaffold pilot

### `supplementary_results/`
Additional results reported outside the camera-ready paper because of space constraints, including demographic summaries and robustness analyses.

## Data Availability

Study materials, scoring rubrics, analysis scripts, qualitative coding materials, supplementary results, and VulnScaffold materials are publicly available in this repository.

Participant-level data are not publicly released to protect participant privacy and to remain consistent with the approved IRB protocol.
