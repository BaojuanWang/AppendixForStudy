
# Main Study Materials

This directory contains materials used in the main study.

## Contents

- `code_snippets/`: code examples used in the vulnerability-learning tasks
- `survey/`: survey instrument used for participant screening, study measures, and post-task responses
- `scoring_rubrics/`: rubrics used to score the five vulnerability-understanding dimensions
- `coding_schemes/`: coding materials used for qualitative responses

The five assessed dimensions are Recognition, Cause, Behavior, Danger, and Fix.
