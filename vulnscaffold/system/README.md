# VulnScaffold System

This directory contains the implementation of VulnScaffold used in the pilot evaluation.

## Contents

- `interface/`: VulnScaffold learner interface
- `server/`: backend server and dependencies

VulnScaffold was developed after the main study and uses a different implementation structure from the plain LLM interface used in the main study. The corresponding pilot study materials and analysis artifacts are organized separately under `vulnscaffold/pilot_evaluation/`.
